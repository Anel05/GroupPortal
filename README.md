# GroupPortal

**GroupPortal** — Android-приложение для просмотра списка студентов и их успеваемости.

## Возможности

- Ввод имени пользователя.
- Просмотр списка студентов.
- Просмотр оценок по отдельным предметам.
- Отображение среднего балла студента.
- Передача данных между экранами приложения с помощью Intent.

## Версии SDK

- **minSdk:** 26
- **targetSdk:** 37
- **compileSdk:** 37

## Используемые технологии

- **Язык программирования:** Kotlin
- **Среда разработки:** Android Studio
- **Интерфейс:** XML Layouts
- **Архитектура экранов:** Activity и явные Intent
- **Java:** 11

## Требования к запуску

- Android Studio с поддержкой Gradle.
- Android SDK, необходимый для сборки проекта.
- Эмулятор Android или физическое Android-устройство.
